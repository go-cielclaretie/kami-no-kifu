# 行書体の設定

**フォントファイル本体は同梱していません。** 数字による手数表示には、この設定は不要です。

## 利用者が手元のフォントを使う

「表示設定 → 棋譜画像 → 手数を表示 → 漢数字」で行書体を選択します。
端末の認識可能な行書体を試し、見つからなければフォントファイル選択欄を表示します。
TTF / OTF / WOFF / WOFF2、25 MiB以下に対応します。TTCコレクションには対応しません。
フォントはブラウザのFontFaceへ読み込み、選んだファイルを送信・保存しません。
タブを閉じると選択は失われるため、次回は再選択します。選んだ書体が行書体かどうかを自動鑑定する機能はありません。

## 運営者が自動読み込みを用意する

Webフォントとして公開・再配布する権限を確認したうえで、自分で用意したフォントを同じサイトへ配置します。
フォントを使用できることと、公開リポジトリに含められることは同じとは限りません。

例：`assets/fonts/gyosho.woff2` を配置した場合、`js/config.js` の設定を次に変更します。

```js
gyoshoFonts: Object.freeze([
  { path: 'assets/fonts/gyosho.woff2', name: '使用する行書体の名前' }
]),
```

ファイルパスは相対パスで指定します。外部URL、GAS URL、Google Drive共有URL、先頭 `/` は使いません。
外部サイトを直接fetchすると配布形式・CORS・公開権限の問題が起きるため、この版は同一サイト内に限定しています。
ファイルが無ければ404として表示し、手動選択への案内を出します。タイムアウトや25 MiB超も処理します。

`.gitignore` は意図しないフォント公開を防ぐためフォントディレクトリの本体を既定で除外しています。
公開権限の確認後に、そのファイルだけ明示的にコミットしてください。
Nodeの `build` はフォントディレクトリをコピーしますが、配布物に存在しないフォントを取得・同梱はしません。

TTF等をURL/ArrayBufferからブラウザへ登録する仕様：
https://developer.mozilla.org/en-US/docs/Web/API/FontFace
