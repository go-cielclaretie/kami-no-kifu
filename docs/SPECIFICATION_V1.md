# 実装仕様 v1.3.0

## 1. 入力と検査

SGFファイルをファイル選択またはドラッグ＆ドロップで1件ずつ読む。複数対局と分岐を選択できる。構文、盤サイズ、座標、重複着手、手番、取り石、自殺手、単純コウなどを検査する。選択した対局の全分岐が検査対象。9路・13路・19路に加えて規定範囲内の長方形盤も扱う。

日本ルールは単純コウ、中国ルールは過去の同じ盤面を禁止する本アプリの方針で検査。すべての大会の反復裁定・終局規則を再現するものではない。死活・セキ・地合い・勝敗・時間切れは判定しない。途中の局面編集など未対応の形式は理由を表示する。手合いが不明なSGFをコミ0だけで定先と決めつけない。

## 2. 画面

中央の完成プレビュー、左の表示設定、右の対局情報、右上のダウンロード。左右は収納可能。表示設定の折りたたみはすべて閉じて開始し、保存設定の復元でも開かない。設定変更はプレビューに反映する。左パネルの保存ボタンはスクロール領域の外、パネル最下部に配置。左パネルを収納するとボタンも収納される。

SGF未読込・不合格・必須欄不足・不正なページ指定・未読込の行書体などの場合、出力を無効化する。所感の編集時には対応する棋譜図へプレビューを移す。

## 3. 対局情報とレイアウト

黒白の名前、手合い、ルール、コミ、勝敗を必須とする。大会名、場所、日付、段級位、時間、所感は掲載切替可能。SGFを読んだ後も編集できる。所感はSGFコメントから自動転記しない。

タイトルは用紙上部中央の「黒番名前 対 白番名前」。表示を切り替えられる。対局情報はタイトルと盤面の間に配置し、盤面幅の範囲内で中央をそろえる。

| 方向 | 搭載レイアウト |
|---|---|
| 横書き | 1 中央バランス、2 二列整列表、3 対局者カード、4 分類帯 |
| 縦書き | 1 均等列組み、2 罫線整列表、4 二段タイル、5 対局者強調 |

方向を変えても各方向で選んだレイアウトは保持する。番号は前版の提案番号を維持。H5とV3は選択肢に入れない。対局情報量と盤面幅を反復計算して配置する。小さい用紙での過剰な折返しを防ぐため、一定の基準幅で組んだ情報欄を一様縮小する場合がある。過度に長い情報など、収まらない場合はエラーにする。

縦書きの英字は正立。名前の数字は1桁ずつで、段級位の数字列（例10、15）は縦中横。日付は西暦を各桁で縦、月日を縦中横にし、年月日表記を用いる。認識できない日付範囲は原文を保持する。コミ・勝敗の `.5目` は `半目／目半`。編集欄の値は変更しない。持ち時間は意味のまとまりごとに改列し、見出しと値を字下げで区別する。

## 4. 所感

初期値は「最後」。最初・最後・任意ページは複数選択でき、重複は除く。全ページをチェックするとほかの指定より優先し、ほかのチェック欄を無効化する。解除後は以前の選択へ戻る。指定をすべて外した場合は所感を載せない。

任意ページは `2,4-6` のような番号・範囲。全角数字や読点も受け付ける。0、存在しないページ、逆順の範囲、不正な書式はエラー。全ページが優先されている間は非適用の任意ページ範囲を検査しない。

「全ページ」の本文方式は「すべて同じ所感」「ページごとに異なる所感」。後者は各棋譜図に対応するテキスト欄を生成する。共通本文と個別本文は別々に保持し、切り替えても削除しない。空欄のページには共通本文を勝手に代入しない。

ページ番号は補記を含めない **棋譜図の通し番号**。番号指定は手数に追従するものではない。分割数を変えたときは内容を見直す。現在のページ数を超えた本文はメモリに保持するが出力しない。SGFを新規読込するとすべての所感を初期化する。

所感は各対象棋譜図の下へ掲載し、長文の残りは棋譜図の後に補記として追加する。全ページ・共通本文の続きは共通補記に1回だけ出す。それ以外は参照元の第N譜を示して続ける。1本文12000文字、個別本文の合計120000文字以内。出力は補記を含め300ページ以内。

## 5. 時間設定

掲載チェックがあるときだけ方式・数値を必須として検査する。非表示モードの数値は保持するが、現在の方式の検査・出力には使わない。

| 方式 | 表示する入力欄 |
|---|---|
| 日本式 | 持ち時間（分）、秒読み（秒）、回数（回） |
| カナダ式 | 持ち時間（分）、予備時間（分）、手数（手） |
| フィッシャー式 | 持ち時間（分）、加算時間（秒） |
| 切れ負け | 持ち時間（分） |
| 秒読み | 一手あたり（秒） |
| NHK杯式 | 一手あたり（秒）、考慮時間（秒）、回数（回） |

回数・手数は1以上の整数。持ち時間と加算時間は0以上、秒読み・一手あたり・予備時間・考慮時間は正数。分数入力も可。6方式にルール運用や時計計測機能は含まれず、棋譜への記録・印字だけを行う。

SGFのTMは秒から分へ変換。OTは自由文のため、明確な形式だけを解析し、それ以外は原文を見せて手入力を求める。TMだけでは切れ負けと推測しない。対応例は `3x30 byo-yomi`、`25/600 Canadian`、`Fischer 10`、`absolute`、`30s/move`、`NHK 30s + 10x60s`。旧版内部名 `swiss` は日本式へ移行する。

## 6. 盤面・番号・素材

総譜、50手・100手・任意手数の分割。前譜から残った石に番号を再表示しない。漢数字では100手分割に固定し、101手・201手を一から再開。数字へ戻すと直前の総譜／分割・分割手数を復元する。

数字は100〜999の文字輪郭を測り、最大外接矩形の対角線が石の直径の85%となる共通サイズ。1〜3桁で同じフォントサイズを用い、輪郭の中心と石の中心を合わせる。漢数字は縦に組んだ輪郭全体の95%で、行書体の読込が必要。フォントそのものは同梱しない。

座標は上・下・右・左に表示でき、上と下の各行は共通ベースライン。盤色6種類、無地・柾目・板目、黒白別のカラーパレット、石の質感・影を選べる。

板目は今回のユーザー提供写真から遠近を補正し、盤線・星を補間して除去した固定素材。素材の色はグレースケールにして盤色に重ねる。写真全体を盤上に貼る方法ではなく、盤線・星・石はアプリが独立に描画する。補間と縮尺変更を含むため原写真の完全複製ではない。柾目と石の模様は既存の数式描画を維持する。

## 7. 再着手・アゲハマ

総譜は各座標で最初に示す石を図に残し、後の同地点着手を `53(46)` などで欄外注記する方式。最終盤面の石だけに過去の番号を無理に載せる方式ではない。左右の注記は縦並び、上下はカンマ区切り。「同地点着手」の見出しは印刷しない。注記全体を盤面の対応軸中央に配置する。

碁石の表示はチェックと「横に小さく／碁石上に表示」の選択。後者では実際の円形の石と番号を描き、参照した過去の手の石色も履歴から取得する。アゲハマは `アゲハマ   黒：4  白：3` の形式で盤面右下。黒白はそれぞれが取った石の数。

## 8. 表示設定の保存

保存ボタンによる明示的なlocalStorage保存。自動保存ではない。読み書きは例外を捕捉し、保存後は同じ文字列を読み返して確認する。形式はバージョン付きJSON、キーは `KifuPrintWeb.display.v1`。既知の設定だけを許可し、壊れたJSON、未対応バージョン、不正な設定値を拒否する。

保存するのは表示設定、所感の掲載方法、漢数字へ変更する前の分割設定。SGF、対局情報、右側の掲載チェック、所感の本文・個別本文、GoogleアカウントID、フォントは含めない。初期化ボタンはその場の設定だけを初期化し、保存済み設定を変更するには再度保存を押す。

同じブラウザプロファイル・配信元内での保存であり、個人認証や端末間同期ではない。保存制限、サイトデータ削除、プライベートモード、配信元変更により復元できないことがある。JSON書き出し／読込で手動移行できる。設定ファイルは50000バイト以下で検証後に適用する。

## 9. 出力

A3、A4、A5、JIS B5の縦横。PDF・PNG・JPG、150/300/600 dpi。大きすぎるCanvasは保護上限で停止する。プレビューと出力は同じページ計画と描画関数を使う。PDFはJPEG画像のページ集合で、文字検索はできない。複数画像はZIPへまとめる。

生成ファイルと保存リンクを作る以外に、Drive・メール・外部ストレージへの自動送信は行わない。
