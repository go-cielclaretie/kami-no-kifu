# 素材・データ・公開時の注意

板目画像はv1.3.0に入っていた、ユーザー提供写真を加工した素材をそのまま継承しています。
写真の権利を新たに確認・取得したという意味ではありません。一般公開する際は元写真の利用許諾を確認してください。
フォント本体は含みません。テストに使う端末側のフォントも配布ZIPに含めません。
サンプルSGFは検証用の架空対局です。実在の棋譜・教材としての品質を主張しません。

サイト側のコードには、SGF・名前・所感・生成画像を送信するAPI、アクセス解析SDK、広告、Cookie認証はありません。
localStorageには明示的に保存した表示設定だけを記録します。
ただしGitHub Pagesへのアクセスに対してGitHubがセキュリティ目的のIPアドレスログを記録することは、公式資料で案内されています。
「通信そのものが無い」「サイト訪問のログも一切無い」という説明にはしないでください。
https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

公開リポジトリ／公開サイトに置くファイルへ、アクセストークン・個人のSGF・公開しない対局名や所感を入れないでください。
公開用の軽量ZIPには開発用のSGF・テストログ・PDF見本は含めません。
本変更でプロジェクト全体へ新しいオープンソースライセンスを付けてはいません。必要な公開・利用条件は所有者が決めてください。
