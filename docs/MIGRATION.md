# v1.3.0（GAS）→ v2.0.0（GitHub Pages）

## 変更したもの

| v1.3.0 | v2.0.0 |
|---|---|
| `Code.gs` のdoGet / HTML Service | `index.html`をそのまま配信。Code.gsは不要 |
| 巨大な `Index.html` 内のCSS/JS | `css/styles.css` と `js/*.js` に分離 |
| GAS `google.script.run` → getGyoshoFont | `font-loader.js` のブラウザ標準FontFace読込 |
| GASサーバーが公式ZIPを取得・解凍 | その仕組みは廃止。端末の行書体、同一サイトの設定済みWebフォント、手動選択へ |
| base64埋込の板目 | 同じ画像を `assets/itame-grain.png` として相対参照 |
| GASマニフェスト・clasp設定 | 不要。配布物に含まない |
| `KifuPrintWeb.display.v1` の保存キー | プロジェクトのパスを含む `KifuPrintWeb.display.v2:/.../` |
| Google認証の配信経路 | 通常の静的HTTP/HTTPS配信。アプリに認証処理なし |

SGF解析・着手検査・設定正規化の `core.js` はv1.3.0の内容をそのまま継承しました。
描画処理は板目の同一サイト画像読み込みとエラーメッセージのみ調整し、レイアウトや石の番号の計算は変更していません。
PDFのProducerはv2.0.0に変更しています。

## 表示設定を引き継ぐ

ブラウザのlocalStorageは配信元ごとに異なるため、新しいGitHub PagesからGASの保存領域を直接読み出すことはできません。

1. GAS版で「設定を書き出す」を押す。
2. v2.0.0で「設定を読み込む」からJSONを選ぶ。
3. 表示を確認し、「表示設定を保存」を押す。

設定JSONのschema:1 / app:KifuPrintWebは互換です。所感本文・対局情報・SGFは元々保存対象ではありません。
GitHub Pagesのプロジェクトごとにキーを分けていますが、これは同一オリジン内での設定衝突防止であり、
別のプロジェクトからデータを完全隔離するセキュリティ境界ではありません。

## 漢数字と行書体

GASのサーバー経由取得がなくなるため、標準配布のままでは「公式サイトから自動でZIPを取得」は行いません。
端末に認識できる行書体があれば利用し、それ以外は手元のファイル選択で使用できます。
運営者がWeb公開可能な行書体を同じサイトへ配置・設定すれば、利用者が選択しなくても読み込めます。
未読込のまま別フォントで漢数字の完成PDFを出さないよう、従来どおり出力を止めます。
詳しくは `assets/fonts/README.md`。この配布物にフォント本体はありません。

## 外部通信・認証

SGFや所感をサーバーに送る処理、Google API、GAS API、外部CDNのPDFライブラリはありません。
HTML・CSS・JS・画像はサイトから配信されます。フォントは運営者が設定したときだけ同一サイトから取得します。
配信元にGoogle Apps Scriptを使わないため、そのWebアプリ特有のログイン経路を通りません。
ブラウザやネットワーク自体の制限まで解消するものではありません。
