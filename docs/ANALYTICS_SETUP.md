# 管理者向け利用統計の設定

この設定では、サイトは統計イベントだけをApps Scriptへ送る。集計結果の読み出し機能はApps Scriptに置かず、管理者だけに共有したGoogleスプレッドシートで確認する。

## 1. 管理用スプレッドシートを作る

1. Googleに `go.ciel.claretie@gmail.com` でログインする。
2. 新しいGoogleスプレッドシートを作る。作成直後の共有範囲は「制限付き」のままにする。
3. 右上の共有設定で、統計を見る必要がある管理者だけを追加する。リンクを知っている全員への共有は使わない。
4. シートの **拡張機能 → Apps Script** を開く。

## 2. Apps Scriptを準備する

1. Apps Scriptエディタの `Code.gs` を空にして、リポジトリの `analytics_gas/Code.gs` の内容を貼り付ける。
2. 保存して、関数一覧から `setupAnalytics` を選び実行する。
3. Googleの権限確認を完了する。スプレッドシートに `日次集計` と `管理ダッシュボード` ができたことを確認する。
4. ダッシュボードのB2で日別・週別・月別・年別・全期間を選ぶと表示が切り替わる。週は月曜日始まり。

出力形式とおすすめ設定の割合は、その期間の成功出力全体が分母。おすすめ以外の設定値は完全一致を除いた出力、近い設定からの変更は近い出力が分母。段級位の割合は黒番・白番ごとに認識できた段級位の入力件数が分母。近い設定は複数項目が変わることがあるので、変更割合の合計は100%を超える場合がある。

`日次集計` シートには日本時間の日付と、指標・項目・値ごとの合計件数だけが保存される。個別イベントの時刻・訪問者ID・IPアドレス・SGF・入力文字列は保存しない。

## 3. 匿名POSTの受信口を公開する

1. Apps Scriptで **デプロイ → 新しいデプロイ → ウェブアプリ** を選ぶ。
2. 実行するユーザーを自分（`go.ciel.claretie@gmail.com`）にする。
3. アクセスできるユーザーは、匿名のサイト訪問者が使える選択肢にする。Google Workspaceの管理ポリシーによっては「全員」などの公開が選べないことがある。
4. デプロイして表示された `/exec` URLを控える。`/dev` URLではなく `/exec` を使う。

受信口は公開URLだけど、`POST`された検証済みイベントを日次件数へ加えるだけ。`GET`では固定の説明文を返し、シートの統計は返さない。匿名受信のため投稿の偽造までは防げず、件数は概算。

## 4. サイトに受信先を設定する

1. `js/config.js` の `analyticsEndpoint` を、発行した `/exec` URLに置き換える。

   ```js
   analyticsEndpoint: 'https://script.google.com/macros/s/デプロイID/exec',
   ```

2. 変更を公開する。通常のファイル配布なら `index.html`、`privacy.html`、`js/`、`css/`、`assets/` を更新する。ビルド配布なら `npm run build` 後の `dist/` を公開する。
3. `privacy.html` を開き、送信項目の説明がサイトで見えることを確認する。
4. スプレッドシートの共有設定をもう一度見て、管理者以外へ共有されていないことを確認する。

受信先URLはサイトの公開コードに含まれる。これは秘密鍵ではなく、公開サイトからPOSTできる宛先。Apps Scriptの所有権、シートの共有権限、アカウント情報は公開コードへ追加しない。

## 無効化と障害時

- 無効にするには `analyticsEndpoint` を空文字へ戻してサイトを再公開する。
- 受信先未設定、`file://` のオフライン版、ブラウザがオフラインと判定している場合は送信しない。
- 通信に失敗してもPDFや画像の保存を続ける。送信失敗分は再送せず、統計は概算になる。
- Apps Scriptの公開が組織ポリシーで許可されない場合、URLを設定せず利用統計を無効のままにする。
