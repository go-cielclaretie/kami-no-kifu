# 変更履歴 — v2.0.0

リリース作成日：2026-09-19。基準版：この会話で配布したKifuPrintWeb v1.3.0。

## GitHub Pagesへの移行

- GASのページ配信・マニフェスト・clasp・Google API呼出しをアプリから撤去。
- 小文字の `index.html`、`js/`、`css/`、`assets/` に分割。リポジトリ直下へ置くだけで公開できる構成。
- サイトのルート、プロジェクトパス、入れ子のパスで素材・スクリプトを相対参照。
- 9つのJavaScriptは順序を守ってdefer読込。初期化中の案内を追加。
- 画像・コードを同じサイトから配信し、外部CDNやサーバー処理を必要としない。
- CSPを設定。通常版は同一サイトのスクリプト、単体版は生成時のハッシュで許可。
- バージョン表示、PDFのProducer、資産URLのキャッシュ識別を2.0.0へ更新。

## 表示設定

- 保存キーをサイトのパスで分離。同一github.io内に複数のプロジェクトがあっても、通常の利用で設定を上書きし合わない。
- 元のschema:1のJSONを受け入れる。GAS版の書出し→v2の読込み→明示保存で移行。
- 対局者名・所感本文・SGFは引き続き保存対象外。保存タイミングも手動のまま。
- オリジンが変わるため、GASのlocalStorageを直接引き継ぐ処理はない。

## 行書体（移行時の変更点）

- GASサーバー経由のZIP取得・解凍は廃止。
- 端末で認識できる行書体、運営者が設定した同一サイトのWebフォント、利用者が選んだファイルに対応。
- 同一サイトフォントはサイズ制限、タイムアウト、中止、HTTPエラー、拡張子・バイナリ形式の検査を追加。
- 読込みが競合した場合に古い結果で新しい選択を上書きしない。
- 未読込時の漢数字出力停止を維持。選択した書体そのものが行書体かは人が確認する。
- フォント本体は同梱しない。標準配布状態では外部フォントサービスへ通信しない。

## 変えていない棋譜機能

SGF解析・合法性検査のcore.jsと板目画像の原本はv1.3.0とバイト単位で同一。
所感の掲載先・ページ別本文、8レイアウト、6持ち時間方式、番号・座標・石と盤の素材、
用紙・出力形式・画像ZIPなどは引き継いだ。
描画処理は素材URLと関連するエラー説明の修正のみで、棋譜レイアウトの再設計はしていない。

## 開発・配布

- npm依存なしの構造検査、テスト、dist生成、ローカルHTTPサーバー。
- 任意のGitHub Actions公開テンプレート。標準の公開方法では不要。
- 完全版ZIPと、公開用ファイルだけの軽量ZIP。
- 新ソースで再生成した見本PDF、実行ログ、v1.3.0との描画比較を同梱。

検証済み範囲・未確認範囲は [TEST_REPORT.md](TEST_REPORT.md) を参照。
